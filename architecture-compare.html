📋 优化总结

去掉的

  • 顶部"日历"一级Tab（内容太单薄）
  • 右侧大日期卡片（用户已经知道今天几号）
  • 右侧本周日历（和月历功能重复）

保留的（换了位置）

  • 日期+农历+节日 → 精简为右侧顶部一行
  • 完整月历+标记 → 点击日期行弹出
  • 每日一句 → 月历弹出层底部展示
  • 历史打卡查看 → 月历点击日期查看

增强的

  • 复习看板：增加学习统计、错题本入口、学习日历
  • 右侧面板：打卡+待办+学习完整展示，不用滚动
  • 顶部导航：3个Tab更清晰，决策成本更低

核心收益

  • 信息密度匹配：3个看板都是"有内容的"
  • 日历无处不在：每次打开都能看到日期，但不抢视觉
  • 右侧更实用：今日相关信息集中，一目了然
