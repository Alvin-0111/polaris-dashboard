Talos Dashboard 个人工作台 · 产品功能文档

版本：v1.0（对应 2026-09-18 代码基线）
文档性质：面向 产品经理 / UI 设计师 / 前端开发 / 终端用户 的完整功能规格说明
说明：本文档描述的是 Obsidian 插件 talos-dashboard-obsidian（Talos-Dashboard 个人工作台仪表盘）的真实运行功能，所有"点击 → 跳转"均为插件内已实现的交互闭环。

一、产品概述

1.1 产品定位

一个运行在 Obsidian 内的个人知识管理工作台，将任务管理、笔记/知识库洞察、间隔重复复习、习惯打卡、日期信息整合进同一界面，数据与 Obsidian Vault 双向实时同步。

1.2 核心价值

价值说明
一体化工作（任务/时间线）、知识（笔记统计/热力图）、复习（间隔重复）三块在一个看板中切换，无需在多个插件间跳转
数据真实所有统计来自 Vault 真实笔记与插件持久化数据（data.json），非演示数据
可交互任务可拖拽改期/跨列、热力图可点选、复习可完成/跳过/标记错题、日历可展开
不污染笔记任务、打卡、复习记录全部存插件 data.json，不写回笔记 frontmatter
双主题深色 / 浅色完整适配，组件级两套样式

1.3 目标用户

Obsidian 重度用户，有任务追踪、知识库沉淀、规律复习、习惯养成需求；期望在 Obsidian 内获得"仪表盘"式的一屏总览。

1.4 设计语言

参考 CRM Dashboard 风格：淡黄绿主色 + 淡紫辅助色 + 大圆角 + 柔和阴影；完整规范见 DESIGN-SYSTEM.md（深色/浅色双模式）。

二、打开方式与安装

2.1 打开

  • 点击 Obsidian 左侧 Ribbon 栏的 layout-dashboard 图标（Talos Dashboard）。
  • 或命令面板（⌘P）执行「打开 Talos Dashboard」。

    • 2.2 安装位置

  • Vault 路径：/Users/xiaoshuai/Documents/Obsidian Vault/
  • 插件目录：.obsidian/plugins/talos-dashboard-obsidian/（manifest id：talos-dashboard-obsidian）
  • 构建：cd /Users/xiaoshuai/Desktop/talos-dashboard-plugin && npm run build
  • 部署：cp dist/main.js "…/talos-dashboard-obsidian/main.js"
  • 代码修改后需完全重启 Obsidian（Cmd+Q），插件才会加载新代码。

    • 四、顶部导航栏

    4.1 Logo（Talos）

  • 品牌标识：八角星 Logo（品牌黄绿 #c8e060）。
  • 纯展示，无跳转。

    • 4.2 看板切换 Tab

  • 三个 Tab：💼 工作看板 / 📚 知识库看板 / 🎯 复习看板。
  • 点击切换主内容区，右侧今日面板保持不变；切换时 Toast 提示「已切换到 XX」。
  • 复习角标：当日有到期复习时，「🎯 复习看板」Tab 右侧显示红色数字角标（今日待复习数，≥100 显示 99+）；无到期不显示；完成/跳过复习后切看板刷新。

    • 4.3 全局搜索（⌘K）

  • 位置：导航栏中部搜索框，占位文案「搜索笔记、任务、文档...」，右侧 ⌘K 快捷键提示。
  • 交互：
  • 输入即搜（220ms 防抖），在搜索框下方展开连体下拉面板（Google 式：搜索框与结果面板为一体，输入时搜索框高度拉伸包容结果，底部圆角归零，结果区与输入区以浅色分割线分隔，分割线不与外框相连、两端留白）。
  • 结果按 📄 笔记 / 📋 任务 / 📚 复习 分组，每组标题显示命中条数；每组最多展示 6 条，超出部分不展开（无底部"查看全部"跳转的为纯截断展示）。
  • 笔记项：主行 = 文件名（匹配词高亮），副行 = 完整文件夹路径；长文件名做"窗口截断"，保证匹配词始终落在可视窗口内。
  • 任务项：主行 = 任务标题，副行 = 状态 · 优先级 · 截止日期（如 进行中 · P0 · 08/18）。
  • 复习项：主行 = 学科名（或文件名），副行 = 笔记路径。
  • 键盘导航：↑/↓ 在结果间移动高亮；Enter 打开当前高亮项；无高亮时 Enter 打开 Obsidian 全局搜索面板；Esc 关闭下拉。
  • 跳转：点击笔记/复习项 → 打开对应笔记；点击任务项 → 打开任务详情抽屉。
  • 相关度排序（笔记）：标题完全等同 > 标题前缀命中 > 标题包含（越靠前越相关）> 仅路径命中；assets/附件/素材 类附属笔记降权但保留。
  • 底部兜底：无匹配时显示「未找到与「XX」相关的内容」。

    • 4.4 操作按钮

  • 📝 写日记：调用 Obsidian 原生日记命令（daily-notes:open-today），打开今天的日记笔记（不存在则按原生日记配置创建）。与 Obsidian 原生日记完全同步，非插件自建日记体系。
  • ⚙️ 设置：打开插件设置弹窗（详见「九、设置面板」）。

    • 五、工作看板

    5.1 数据概览（4 张统计卡）

  • 展示：待办任务 / 进行中任务 / 已完成任务 / 逾期任务 四类卡片，数字实时从任务数据计算。
  • 卡片结构：左侧语义色图标（⏳蓝 / 🚀绿 / ✅紫 / ⚠️红）+ 右侧大数字 + 标签 + 注释行（如「占全部任务 33%」「完成率 22%」「需尽快处理」）。
  • 点击跳转：点击卡片 → 任务看板滚动定位并切换对应筛选列（如点「逾期任务」→ 看板切换到逾期视图）。
  • 口径：逾期 = 未完成且截止日期早于今天（isTaskOverdue 动态计算，非静态字段）；「待定」截止日期不判逾期。

    • 5.2 焦点任务（今日焦点）

  • 展示：自动挑选的"当前最该推进"的任务：逾期优先 > 优先级（P0>P1>P2）> 截止日期近 > 进行中优先。
  • 卡片信息：状态徽标（已逾期/最高优先）、负责人、截止日期、任务标题、进度条（百分比）。
  • 操作：
  • 「继续编辑」→ 打开任务关联的笔记（notePath）。
  • 「查看详情」/ 点击卡片 → 打开任务详情抽屉。
  • 无待办任务时显示空态提示。

    • 5.3 项目时间线（甘特图）

  • 展示：任务按时间轴分布的任务条；标题显示在任务条内；逾期任务自动标红。
  • 视图切换：右上角 周 / 月 / 季 / 年 四档（对应任务条按天/月对齐）。
  • 拖拽改期（核心交互）：
  • 按住任务条整体左右拖动 → 起止日期同步平移；
  • 拖任务条左/右边缘（光标变 ↔）→ 只调整开始 / 截止日期；
  • 拖动中鼠标旁实时跟随日期浮层（整体平移显示 开始 ~ 截止，拖边缘显示 开始/截止 MM/DD；拖到今天之前追加红色「⚠ 将逾期」提示，已完成任务除外）；
  • 松手按天对齐 → Toast「已更新日期」→ 任务看板 / 今日待办 / 焦点任务 / 统计卡全部联动刷新，并持久化到 data.json（重启不丢失）；
  • 硬约束：开始 ≤ 截止（拖边缘自动钳制）、不拖出当年。
  • 点击任务条 → 打开任务详情抽屉。

    • 5.4 任务看板（可拖拽）

  • 筛选：顶部 5 个状态筛选按钮 全部 / 待办 / 进行中 / 已完成 / 逾期（点击数据概览卡片会自动切到对应筛选）；右侧搜索框按关键词过滤任务。
  • 列布局：按当前筛选显示列（默认待办 / 进行中 / 已完成三列），每列任务卡片含：优先级（P0/P1/P2）、日期（MM/DD）、任务标题、4 段分段式进度条（0% / 25% / 50% / 75% / 100% 点击精确选择）、左侧状态色条（进行中蓝 / 已完成绿 / 逾期红）。
  • 跨列拖拽：把任务卡片拖到其他列 → 状态即时改变。
  • 点击任务卡片 → 打开任务详情抽屉。

    • 5.5 任务详情抽屉

  • 形态：从右侧滑出的抽屉，覆盖主内容区，右上角 ✕ / 点击遮罩关闭。
  • 字段：状态徽标、优先级、开始日期、截止日期、负责人、进度、标题、描述、关联笔记。
  • 可编辑：
  • 状态（待办 / 进行中 / 已完成）即时切换；
  • 优先级（P0 / P1 / P2 平铺分段，点击即选）；
  • 开始 / 截止日期（点击弹出日期选择器：当月日历网格、‹ › 翻月、「今天」快捷定位、「清除」置空；点外部关闭）；
  • 负责人（文本修改）；
  • 「打开笔记」：有 notePath 时一键打开关联笔记。
  • 「完成任务」：一键标记完成（进度 100%），移入已完成列，各面板联动。
  • 「编辑任务」：打开编辑表单（见 5.7）。
  • 联动：抽屉内任何修改即时落盘并刷新甘特图 / 看板 / 统计 / 今日待办 / 焦点。

    • 5.6 新建任务（＋ 新建任务）

  • 入口：工作看板右上角「＋ 新建任务」。
  • 表单字段：
  • 任务标题（必填）；
  • 描述（选填）；
  • 优先级（P0/P1/P2 平铺分段，默认 P1）；
  • 开始日期（选填，日期点选）；
  • 截止日期（选填，日期点选；不填则存「待定」——甘特图按今天占位、不参与逾期判定）。
  • 保存：创建成功 → Toast「任务「XX」创建成功」→ 任务 ID 自动递增（WXB-XXX）→ 看板 / 甘特图 / 今日待办 / 统计即时联动 → 落盘 data.json。

    • 5.7 编辑 / 删除任务

  • 入口：任务详情抽屉 →「编辑任务」。
  • 可编辑：标题、开始日期、截止日期、负责人、关联笔记路径（notePath 支持输入如 01-Projects-项目/任务笔记.md）。
  • 删除：编辑弹窗底部「🗑️ 删除任务」→ confirm 二次确认（不可恢复）→ 删除后全部视图联动刷新 + 落盘。
  • 样式规范：所有表单输入框统一 UI 规范（圆角、边框、聚焦态，与搜索框一致）。

    • 六、知识库看板

    6.1 统计卡（4 张，点击弹窗）

  • 展示：总笔记数 / 断链笔记 / 空笔记 / 本月新增，全部来自 Vault 实时统计（getVaultStats()，使用 Obsidian API）。
  • 点击跳转（弹窗列表）：
  • 总笔记 → 「📚 全部笔记（共 N 篇，展示最近 100 篇）」；
  • 断链笔记 → 「🔗 断链笔记（N 篇文档 · 共 M 处断链）」；
  • 空笔记 → 「📄 空笔记（共 N 篇）」；
  • 本月新增 → 「✨ 本月新增（共 N 篇）」。
  • 弹窗结构：标题 + 搜索框（实时按名称/路径/副行过滤）+ 笔记列表（名称 + 副行：断链篇数/所在文件夹）+ 底部「过滤数 / 总数 篇」统计 + 「关闭」按钮。
  • 跳转：点击列表项 → 关闭弹窗 → 打开对应笔记。
  • 口径：
  • 断链 = 解析全部笔记的 wiki 链接（跳过外部 / 邮件 / www 链接）后目标不存在的链接数；单篇解析失败不影响整体。
  • 空笔记 = 内容为空的笔记。
  • 本月新增 = 本月创建（或修改）的笔记数，注释行显示与上月对比（如「较上月 -234 篇」）。

    • 6.2 笔记产出（柱状图）

  • 展示：按时间统计的笔记产出量。
  • 操作：右上角 年 / 月 / 周 视图切换。

    • 6.3 领域分布（PARA 分布，横向条形图）

  • 展示：按 PARA 一级文件夹（Projects / Areas / Resources / 其他…）聚合的笔记数量与占比横向条。
  • 实时统计：基于 Vault 真实文件夹结构，自动适配任意库结构（可复用）。

    • 6.4 活跃度热力图

  • 展示：Vault 每日活跃度（当天有笔记的天数按强度着色），支持 年 / 月 / 周 多档视图切换。
  • 月视图：整月日历网格（7 列），日期格显示日期数字，活跃度着色。
  • 年视图：全年按月分块（适配窄卡片：按网格密度自适应，如一行 3~4 个月），支持展开查看。
  • 周视图：以周为单位展示近 90 天活跃分布。
  • 今日标识：今日日期带品牌绿外框（细描边，非粗框）。
  • 统计行：连续活跃天数、累计活跃次数、最活跃天数等。
  • 点击某一天 → 右侧展开「当日日志」详情面板，按文件夹分组展示当天产生的内容。
  • 「📝 生成日报」：当日日志面板内一键生成结构化日报并保存到日记文件夹。

    • 6.5 标签 Top10

  • 展示：Vault 中使用频率最高的 10 个标签（点击可展开查看全部标签）。
  • 跳转：点击标签 → 打开 Obsidian 标签面板（右侧边栏）。

    • 6.6 最近笔记 / 收藏笔记

  • 最近笔记：Vault 真实最近修改笔记列表（相对时间，如「3分钟前」），点击直接打开。
  • 收藏笔记：
  • 兼容新版书签插件与旧版星标插件；

  • 本周学习天数 = 本周（周一起）有复习记录的天数；

  • 操作：
  • 点左侧圆圈 ✓ → 标记完成，进入遗忘阶梯（下次到期按 1→3→7→14→30 天 推进），统计卡 / 进度圆环 / 趋势实时联动；第 5 轮走完视为已掌握；

  • 点任务行 → 直接打开对应笔记。

    • 十一、设计规范摘要

    完整规范见 DESIGN-SYSTEM.md。以下为关键约定。

    11.1 色彩（深色主题主色板）

  • 主色（品牌绿）：#c8e060（黄绿）；深档品牌绿：#a8c040 左右
  • 辅助色：淡紫 #a78bfa；语义：进行中蓝 / 完成绿 / 逾期红
  • 背景：#0f0f13（带蓝灰相深色）；卡片：半透明 + 毛玻璃
  • 浅色模式：背景近白，品牌绿降饱和（如柔和浅绿），保证对比度、不刺眼

    • 11.2 圆角

  • 大卡片 / 主要按钮：16px；图标按钮 / 输入框：12px；分段控件 / 小标签：8px；胶囊：999px

    • 11.3 间距（4px 栅格）

  • 大卡片间距：16px；卡片内边距：16px；卡片内模块间距：12px；小元素间距：8px

    • 11.4 按钮三态

  • 主要按钮：品牌绿底 + 深色文字（非白色）；hover 加深 + 光晕
  • 次要按钮：透明 + 浅边框；hover 变绿边框
  • 图标按钮：淡灰底；hover 变绿
  • 危险按钮：红底/红边（删除等）

    • 11.5 搜索框 / 输入框规范（全局统一）

  • 统一圆角、边框、内边距；聚焦态：细品牌绿描边（1~2px，暗色 70% 不透明度 / 浅色用深绿）+ 柔光发光；所有弹窗内输入框同规范。

    • 11.6 主题适配原则

  • 同一组件深色/浅色各一套样式；切换主题时全局重渲染（图表/进度条/热力图同步换色）；卡片阴影、投影在浅色模式弱化。

    • 十二、已知限制与注意事项

  1. 生效方式：修改代码后必须 npm run build + 部署 + 完全重启 Obsidian（Cmd+Q）；只重载插件可能有缓存，代码改动不生效。
  2. 插件识别：插件目录下可能有多个 dashboard 类插件，确认启用的是「Talos-Dashboard 个人工作台仪表盘」（manifest id：talos-dashboard-obsidian）。
  3. 任务数据源：任务目前全部为 UI 手动维护（创建/拖拽/改状态），不支持自动解析笔记待办语法（source 字段已预留，后续按需接入）。
  4. 卡片组件化（拖拽调序/调宽）：已确认后期再做，当前为固定布局。
  5. 自动化限制：部分拖拽手势（如跨列拖拽、甘特图拖边缘）依赖鼠标按住拖放，自动化测试环境无法完全模拟，需人工复核。
  6. 每日一签：仅当天有效，次日自动重置；不提供补签。
  7. Obsidian 原生设置：插件 ⚙️ 打开的是插件自己的设置；Obsidian 原生设置请用 ⌘,。
