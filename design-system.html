1.6 绿色单轨制（核心规则，双主题通用）

一个屏幕上只允许出现一种品牌绿（

>

#c8e060

>

）。

>

品牌绿只用于 "图形语言"，不用于 "文字语言"。
角色暗色模式浅色模式说明
品牌绿（--brand-green）#c8e060#c8e060图标、进度条填充、按钮 / 选中态底色、边框、强调、装饰
品牌色文字（--text-brand）#c8e060#1a1a1f（文字主色）需要 "读" 的文字 / 数字（统计数字、百分比、标签文字、日期数字等）。暗色下绿字对比度足够；浅色下回落文字主色，避免 "深一档绿" 与品牌绿并存的视觉混乱
  • 禁止在浅色模式下把文字 / 数字做成 #a8c040 之类 "深一档绿"—— 浅底上它看起来像另一种颜色，与图标绿不统一。例外①：badge 标签（如 "任务关联"）是 "浅绿底 + 同色系字" 的标签样式，浅色下文字可用 #a8c040（深黄绿）保持色系统一、避免纯黑生硬；该例外只适用于带浅绿底色的标签，不适用于无底色的大数字 / 正文。例外②：日期大字（--date-text，日历卡片上的日期）浅色模式允许使用主色深档 #a8c040—— 日期是唯一 "无底色但仍用深档绿" 的元素（用户确认：浅色日期用品牌色深档，既有绿色感又可读），其余大数字 / 百分比仍回落到 --text-brand（#1a1a1f）。
  • 语义状态色（成功 #22c55e、逾期 #f87171 等）属于状态系统，与品牌绿并存是正常的多色语义，不受此规则约束。

4.2 应用规则

  • 大卡片之间（上下 / 横向）：12px（--space-md）—— 统一由 .dash-grid 网格 gap 控制（12 列卡片组件化网格），三个看板一致
  • 看板标题行与卡片网格间距：12px（--space-md）—— 由 .canvas-header 的 margin-bottom 控制
  • 双栏 / 多列大模块之间：16px（--space-lg）—— 如中部两列、知识图表两列、复习两列、统计卡网格
  • 卡片内边距：16px（--space-lg）
  • 卡片内模块间距：12px（--space-md）
  • 小元素间距：8px（--space-sm）
  • 主内容区左右内边距：20px（上下 16px）
  • 所有间距必须是 4px 的倍数，禁止出现 5px、7px、10px 等非标准值

7.4 拖拽排序与手柄规范（v3 定稿）

依据 1.6 绿色单轨制：拖拽是"图形语言"，反馈色必须使用品牌绿 #c8e060，禁止状态绿（成功 #22c55e）、紫色或其它色。

拖拽手柄（⠿）

  • 尺寸：14×14px，字符 ⠿，颜色 rgba(255,255,255,0.55)（浅色 rgba(0,0,0,0.5)），常态透明度 0.4
  • hover 反馈：浅绿背景块 rgba(200,224,96,0.16) + 放大 1.12 倍 + 品牌绿
  • 手柄距卡片左缘：20px，全插件统一（左栏看板卡 / 右栏四卡），实现方式：

- 左栏 dash-card：卡片内边距 16px + 标题行 padding-left:4px = 20px - 右栏玻璃卡（打卡/番茄）：卡片内边距 16px + 标题行 padding-left:4px = 20px - 右栏紧凑卡（待办/快速记录）：卡片内边距 12px + 标题行 padding-left:8px = 20px

卡片圆角（拖拽边框样式统一的前提）

  • 左栏看板卡 dash-card 与右栏四卡（打卡/番茄/待办/快速记录）统一 --radius-xl（20px）
  • 禁止单卡使用 --radius-md（12px）作为卡片圆角——大卡片圆角只有一档

右栏标题行间距（手柄 | 竖条 | 标题文字）

  • 手柄 → 竖条：8px（--space-sm）
  • 竖条：4×24px，品牌绿 #c8e060，圆角 2px，与手柄右侧间距 8px
  • 竖条 → 标题文字：8px（--space-sm）
  • 标题文字：20px / 600 / --text-primary
  • 标题 emoji 与文字间距：6-8px（图标规范 9.x）

拖拽反馈（操作态，左右栏一致）

  • 拖拽中卡片：rotate(2deg) scale(1.02)，边框品牌绿 #c8e060（硬编码，不得用 CSS 变量——拖拽时卡片移入 document.body，变量解析断链）
  • 圆角保持：拖拽中卡片必须保持原有圆角与背景，禁止方角 / 透明——拖拽开始时将 CSS 变量快照到卡片内联样式（snapshotCardVars），左右栏统一
  • 右栏卡片黄绿边框染在内部卡片边框上（> * { border-color:#c8e060 !important }），贴合内部圆角；禁止在外层无圆角的容器画 inset 环
  • 占位符：黄绿虚线 rgba(200,224,96,0.5) + 底 rgba(200,224,96,0.12)
  • 拖拽阴影：0 12px 40px rgba(0,0,0,0.5)

  • 通过 data-theme="light" 属性切换
  • 所有颜色使用 CSS 变量，切换时自动更新
  • 切换动画：0.3s ease

12.2 浅色模式注意事项

  • 绿色单轨制：主色 #c8e060 与暗色完全一致，只用于图形元素（图标 / 进度 / 按钮底色 / 边框 / 选中态 / 强调）。普通文字与数字一律使用&#x20;--text-brand（浅色 =&#x20;#1a1a1f&#x20;文字主色）；唯一例外是日期大字（--date-text 浅色 = 主色深档 #a8c040，见 §1.6）。
  • 切换控件选中态统一：与暗色相同 —— 品牌绿实底 + #0f0f13 深字（见 3.4），不允许 "绿字浅绿底" 变体。
  • 背景改为米白色（#f5f5f0），不是纯白；文字颜色相应加深；阴影整体弱化（§6.2 浅色值）。
  • 边框颜色改为 rgba(0,0,0,0.06)；卡片 hover 边框用 rgba(200,224,96,0.3)。
  • 按钮 hover 高亮统一用品牌绿系（rgba(200,224,96,0.1) 底 + rgba(200,224,96,0.5) 边框），禁止误用成功绿 #22c55e。
  • 装饰色块 alpha 加深（防止与米白背景融合）：统计卡图标底色暗色 0.15 → 浅色 0.25\~0.28（绿 0.28 / 蓝紫红 0.25 / 灰 0.22）；badge-green 浅色 = 底 rgba(200,224,96,0.28) + 字 #a8c040。
  • 进度条 / 分段激活段：浅色与暗色同款品牌绿渐变（#c8e060 → #a8c040），不换色相。

13.4 结果内容规则

1. 相关度排序：标题完全命中 > 标题前缀命中 > 标题包含（命中越靠前越相关）> 仅路径命中。

2. 附属笔记降权但不过滤：命中 assets / 附件 / 素材 / attachments / 结尾 images 的笔记减 500 分，排在正式笔记之后，但始终保留。

3. 超长标题窗口截断：标题超过 52 字符时，截取 "以命中词为中心" 的窗口并在两端补 …，保证关键词一定可见。禁止简单截尾。

4. 副行 = 完整文件夹路径（dirOf = 路径去掉文件名，不做任何省略、不做左侧截断、不去重，逐条展示；>1 层时完整展示全部层级）—— 用户要求 "看全位置"；副行可整行换行，与上方标题同属一个 .tsd-item 块，归属明确。任务副行 = 状态 · 优先级 · 截止（如 进行中 · P0 · 08/18）。

5. 数量上限：每组最多 6 条；总数超出时底部出现「查看全部 N 条」→ 打开 Obsidian 全局搜索并带入关键词。

13.5 键盘与鼠标

按键 / 操作行为
输入防抖 220ms 后刷新下拉
↑ / ↓在当前项间移动（首尾循环），并 preventDefault 阻止输入框光标跳动
Enter打开当前高亮项；无高亮时退回第一条；完全无结果则打开 Obsidian 全局搜索
Esc关闭下拉并失焦
鼠标移入某行该行变为当前项（与键盘共用同一状态，二者不打架）
输入框失焦160ms 后关闭（留出点击结果的时间）

禁止：Enter 无条件打开 "第一条" 而不反映键盘高亮。

13.6 高亮一致性

搜索命中高亮只允许一套：复用看板已有的 .search-hit（品牌绿底色高亮）。禁止另造一套 "仅变色、不产生底色" 的高亮。

13.7 滚动可见性

.tsd-body 使用 6px 细滚动条（rgba(255,255,255,0.16)，hover 提亮至 0.3；浅色 rgba(0,0,0,0.18)），并设 overscroll-behavior: contain。禁止"内容被裁掉却看不出还能滚"。

13.8 空态

无结果时居中显示：放大镜图标（20px / 透明度 0.6）+「未找到与「关键词」相关的内容」，内边距 24px 10px。空态下不显示底部结果栏。

13.9 实现约束（v3 更新，踩坑沉淀）

约束原因
结果行必须用 div[role="button"]，禁止用&#x20;<button>Obsidian 主题普遍给 button 强制高度与底色；一旦强制高度小于内容高度，行内容会溢出到下一行，与下一条的标题重叠
结果行选择器必须带 .talos-search-drop 前缀保证特异性压过主题的按钮 / 列表样式
条目必须两行制：flex-direction:column，标题行 + 独立副行副行与标题同属一个块、上下紧贴，归属一目了然；单行 "标题 + 右侧路径" 在路径很长时互相挤压、仍会错位
副行路径完整展示（word-break:break-all 换行）省略 / 截断路径会让用户找不到文件位置；完整路径配合换行可读
键盘移动高亮时禁止用&#x20;scrollIntoView它会连带把整个仪表盘一起滚走；必须直接改 .tsd-body 的 scrollTop
计数徽标在截断时显示 已显示/总数只显示列出的条数会误导，只显示总数又与列表对不上
